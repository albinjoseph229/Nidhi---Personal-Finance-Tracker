This file is an example. Create a .env file in the root directory and add your actual values.
Remember to prefix all variables with EXPO_PUBLIC_ to make them accessible in the app.

1. Your Supabase project URL (from Project Settings → API)
EXPO_PUBLIC_SUPABASE_URL="https://your-project-ref.supabase.co"

2. Your Supabase anon/public key (from Project Settings → API)
EXPO_PUBLIC_SUPABASE_ANON_KEY="eyJ..."

Note: AI API keys (Gemini/ChatGPT) are entered by the user directly in the app
and stored securely on-device. No server-side AI keys needed.
